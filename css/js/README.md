# TRINVESTE

## Definição

TRINVESTE é a disciplina padrão sobre uma qualidade de vida socialmente aceitável.

O termo deriva de:

TRIO + INVESTIR

Representa o investimento em três dimensões fundamentais da vida.

## Estrutura

### TRINVESTE 1.3
Eixo Espiritual

Base:
- 10 Mandamentos
- Valores morais
- Fortalecimento espiritual

### TRINVESTE 2.3
Eixo Financeiro

Base:
- Empreendedorismo
- Autoemprego
- Investimento
- Lucro

### TRINVESTE 3.3
Eixo Familiar

Base:
- Casamento
- Filhos
- Equilíbrio familiar

## Coordenação

Promover formação, emprego, empreendedorismo e desenvolvimento humano integral.
